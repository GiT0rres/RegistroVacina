# 💉 RegistroVacina

<p align="center">
  Aplicativo Android desenvolvido para registrar, acompanhar e organizar o histórico de vacinação de forma simples e intuitiva.
</p>

<p align="center">
  <strong>Kotlin</strong> • <strong>Jetpack Compose</strong> • <strong>Material 3</strong>
</p>

---

## 📱 Sobre o projeto

O **RegistroVacina** é um aplicativo mobile criado para facilitar o controle da carteira de vacinação digital.

Com ele é possível:

✔ cadastrar vacinas recebidas  
✔ visualizar detalhes de cada dose  
✔ acompanhar próximas vacinas pelo calendário  
✔ manter o histórico organizado em um só lugar  

---

## ✨ Funcionalidades

- 💉 Cadastro de vacinas
- 📋 Visualização detalhada das doses
- 📅 Calendário com próximas vacinas
- 👤 Perfil do usuário
- 🔍 Busca de vacinas cadastradas
- ➕ Adição rápida de novos registros
- 📱 Interface moderna e responsiva

## 🚀 Como executar

### Clone o projeto

```bash
git clone https://github.com/GiT0rres/RegistroVacina.git
```

### Abra no Android Studio

```text
Open an Existing Project
```

Selecione a pasta:

```text
RegistroVacina
```

### Execute

Conecte um dispositivo Android ou inicie um emulador e clique em:

```text
Run ▶
```
